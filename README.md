# Utilitaire

Ce dépôt regroupe deux outils web orientés analyse de données de laboratoire.

## 1) MS/MS Fragment Calculator (`msms_calculator.html`)

Outil interactif pour calculer et filtrer des fragments MS/MS (MALDI-TOF), avec prise en charge des chaînes multiples, ponts disulfure, modifications et matching sur liste de masses.

### Utilisation rapide
1. Ouvrir `msms_calculator.html` dans un navigateur.
2. Renseigner les séquences et paramètres (ponts S-S, modifications, tolérance).
3. Lancer le calcul puis comparer avec votre liste de masses.

## 2) UV-Vis / Plate Reader Viewer (`uv_vis_viewer.html`)

Visualiseur interactif pour données UV-Vis et plaque (plate reader), avec affichage multi-fichiers, gestion des colonnes/séries et personnalisation graphique.

### Utilisation rapide
1. Ouvrir `uv_vis_viewer.html` dans un navigateur.
2. Charger vos fichiers de données (glisser-déposer ou sélection).
3. Explorer, filtrer et comparer les signaux dans l'interface.

## Prérequis

Aucune installation n'est nécessaire pour les deux outils web : un navigateur moderne suffit.
